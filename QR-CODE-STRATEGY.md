## 📏 QR Code Sizing Guide

### Print Sizes

**Business Card:** 0.8" x 0.8" (20mm x 20mm) minimum
**Flyer:** 2" x 2" (50mm x 50mm) optimal
**Poster:** 4" x 4" (100mm x 100mm) or larger
**Table Tent:** 3" x 3" (75mm x 75mm)

**Rule of Thumb:**
- Minimum size: 0.8" x 0.8"
- Optimal scanning distance = Code size × 10
- Larger is always better for accessibility

### Digital Sizes

**Email Signature:** 150px x 150px
**Website:** 200-300px x 200-300px
**Social Media Post:** 500px x 500px or larger
**Presentation Slide:** 400-600px x 400-600px

## 📱 Testing Your QR Codes

### Before Distribution, Test On:

**iOS Devices:**
1. Open Camera app
2. Point at QR code
3. Tap notification that appears
4. Verify it opens correct URL

**Android Devices:**
1. Open Camera app (or Google Lens)
2. Point at QR code
3. Tap to open link
4. Verify correct page

**Different Lighting:**
- Bright sunlight
- Indoor lighting
- Low light

**Different Distances:**
- Very close (2 inches)
- Normal (12 inches)
- Far (3 feet)

**Different Print Quality:**
- High-res print
- Standard printer
- Black and white
- Color

## ✅ Quality Checklist

Before printing or sharing QR codes:

- [ ] QR code scans correctly on both iOS and Android
- [ ] Opens the correct URL
- [ ] Code is large enough (minimum 0.8" for print)
- [ ] Good contrast (dark on light background)
- [ ] No distortion or stretching
- [ ] Tested in poor lighting conditions
- [ ] Text around QR is clear and readable
- [ ] Call-to-action is obvious ("Scan Me")
- [ ] High resolution for print (300 DPI minimum)
- [ ] URL is correct (double-check!)

---

## 🎨 Design Best Practices

### DO:
✅ Use high contrast (black on white works best)
✅ Leave white space around QR code
✅ Test before mass printing
✅ Include clear instructions
✅ Make code large enough
✅ Use high resolution images

### DON'T:
❌ Use low contrast colors
❌ Stretch or distort the QR code
❌ Place on busy backgrounds
❌ Make it too small
❌ Cover parts of the code
❌ Use blurry/pixelated images

## 🆘 Common QR Code Issues

**"QR won't scan"**
- Increase size
- Improve lighting
- Clean phone camera lens
- Remove background clutter
- Increase contrast

**"Opens wrong page"**
- Double-check URL when generating
- Test before printing
- Regenerate if needed

**"Works on iPhone but not Android"**
- Ensure QR is high quality
- Some Android phones need Google Lens app
- Recommend Chrome browser
